# Backend modular propiedad de Agent Trujillo

Eve, las interfaces remotas, el dominio pediátrico, Supabase e integraciones vivirán en `agent-trujillo` como un backend modular desplegable de forma unitaria. Se rechazaron tanto el acceso Supabase-first desde el móvil como microservicios tempranos: esta forma concentra reglas y auditoría sin acoplar Creciendo a Eve ni añadir operación innecesaria.
