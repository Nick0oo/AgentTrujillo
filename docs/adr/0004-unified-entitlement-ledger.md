# Ledger multi-proveedor para entitlements

Apple, Google y Stripe se tratarán como fuentes de eventos comerciales, no como autoridad directa sobre capacidades. Un ledger append-only e idempotente en Supabase derivará entitlements Free/Premium por espacio de cuidado, lo que permite cumplir las tiendas, conservar Stripe para web y reconciliar eventos duplicados o fuera de orden.
