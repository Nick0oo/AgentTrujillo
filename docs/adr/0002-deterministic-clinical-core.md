# Núcleo clínico determinista anterior al LLM

Percentiles, vacunación, límites farmacológicos y red flags se ejecutarán mediante módulos versionados y probados; Eve y los modelos solo los invocan y presentan. Esta decisión evita que cambiar Gemini, OpenRouter o un prompt altere silenciosamente el comportamiento clínico y permite verificar resultados contra fuentes aprobadas.
