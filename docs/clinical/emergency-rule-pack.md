# Emergency rule-pack contract

`emergency-pack-v1` is a strict, non-executable control-plane artifact. It binds a jurisdiction, locale, effective window, algorithm identity, source digests, approved copy keys, bounded literal concept patterns, assertion filters, exact measurements, age basis, and a fixed urgent decision.

This branch contains only synthetic `synthetic_test_only` fixtures. A synthetic fixture proves schema/compiler behavior and cannot be loaded as an active clinical package. Real Colombia and US packages require the module 03 governance chain and separate clinical approval.

The compiler rejects executable expressions, regular expressions, URLs, phone-like literals, treatment/diagnosis/action fields, unknown references, duplicate codes, cross-jurisdiction locale mismatches, and complexity beyond 256 rules, depth 8, 32 predicates per rule, or 5,000 concept patterns.
