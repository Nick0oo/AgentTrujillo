# Response mode examples

These examples illustrate shape and uncertainty only. They contain no clinical rules.

## Guidance — English

Known: the approved source provides general educational information. The child's specific situation is not established here. Next step: review the information with the child's pediatrician if uncertainty remains.

## Orientación — Español colombiano

Lo confirmado es la información educativa de la fuente aprobada. La situación específica del niño no está establecida aquí. Siguiente paso: revisa la duda con el pediatra del niño si continúa la incertidumbre.

## Clarification — English

What country of care should the approved package use? I need that material fact before continuing.

## Revisión profesional — Español colombiano

No puedo resolver esto de forma segura con la información disponible. Te recomiendo consultar al pediatra.

## Recoverable error — English

I could not complete that request because the approved service is unavailable. No change was made; try again later or ask a pediatrician.

## Emergency recommendation — paired wording

English: Only recommend going directly to the emergency department.

Español colombiano: Recomienda únicamente ir directamente al servicio de urgencias.

## No permitido / Non-example

Do not add a diagnosis, a treatment plan, a second action, an invented source, or an executable interface to any mode.
